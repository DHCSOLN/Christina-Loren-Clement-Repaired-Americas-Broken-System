## Staging and Deployment Instructions

To spin up this architecture on a local node or deployment sandbox, execute the following commands in your development terminal:

### 1. Database Provisioning
Ensure a local instance of PostgreSQL is active, then execute the schema setup script:
```bash
psql -U postgres -d soln_academy -f schema.sql
```

### 2. Backend API Instantiation
Install dependencies, initialize environment parameters, and ignite the microservice pipeline:
```bash
npm install express pg
export DATABASE_URL="postgresql://postgres:secret@localhost:5432/soln_academy"
node server.js
```
